# Fingerprint Door lock System

Security Risks: Prevents unauthorized access and alerts users of suspicious
activities.
•Convenience: Allows users to control door locks remotely, check lock status, and
grant temporary access to guests.
•Access Management: Maintains a log of access events for security audits.
•Power Outage Usability: Ensures manual override functionality during power
failures

## Description

•Homeowners: For enhanced home security and remote access control.
•Office Managers: To manage employee access and improve workplace security.
•Property Managers: To facilitate temporary access for maintenance staff or guests.
•Tech-Savvy Users: Interested in smart home integration and IoT solutions.
